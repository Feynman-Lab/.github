### How it works

1. **Tell us what you need.** A useful tool, website, browser extension, script, or automation can start with a simple description.
2. **We choose what to build.** We look for ideas that are useful, feasible, and a good fit for the time we have.
3. **We make selected ideas real.** If we choose yours, we'll get in touch and build it for free.

Anyone can submit an idea. Submitting does not guarantee that we'll build it.

### From the lab

We're at the beginning. As projects take shape, we'll share the finished tools, the problems behind them, and the source code when we can. You can [explore the project collection](https://feynman-lab.github.io/projects/) or [see the source for this website](https://github.com/Feynman-Lab/Feynman-Lab.github.io).
